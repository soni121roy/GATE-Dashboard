# 🎯 GATE 2027 CS - Study Dashboard

A minimal and productive dashboard made for GATE CSE aspirants targeting PSU.

Live Demo: https:https://soni121roy.github.io/GATE-Dashboard/

### ✨ Features
- ⏱️ 25 Min Pomodoro Focus Timer with Start/Pause/Reset
- ✅ Today's Task Manager - Add, Complete, Delete tasks
- 📊 Subject-wise Progress Tracker (DBMS, OS, CN, Aptitude)
- 💾 LocalStorage support - Data will not be lost on refresh
- 📱 Fully Responsive - Works on mobile & desktop
- 🎨 Clean Dark UI with neon accent

### 🛠️ Tech Stack
- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript (No framework)

### 🚀 How to Use
1. Clone the repo
2. Open `index.html` in browser
3. Add your daily GATE topics and start focusing!

### 📚 Why I Built This?
As a B.Tech CSE student (2028 batch) preparing for GATE 2027 for PSU, I needed a simple tool to track daily targets without distraction of heavy apps.
